# WIN直貼りテスト

これは外部ホスティングを使わず、実際のJSA ReactバンドルがWINのWebsite Custom JavaScriptで実行できるかだけを確認するテストです。WINに恒久導入する方法ではありません。

## 作成

リポジトリのルートで以下を実行します。

```bash
npm run build:win:paste
```

生成される `dist-win/jsa-win-direct-paste.html` の中身を、先頭のコメントを含めてすべてコピーします。

## WINで試す

1. 公開中のページを変えないため、WINで検証用ページを1つ作る。
2. Website Settingsの **Website Custom JavaScript** を開く。
3. 既存内容があれば安全な場所へ控えを取り、このテストの内容へ一時的に置き換える。
4. 保存して、ログインしていないブラウザまたはシークレットウィンドウで検証用ページを開く。
5. `React is running on WIN.` と赤いボタンが見えれば成功。

失敗時は、表示されるエラー、何も表示されないか、コードが文字として出るかを記録する。Custom JavaScript欄の文字数上限で保存時に切り詰められる場合、直貼りテストは失敗扱いにして、外部公開したJSを短いローダーで読み込む方法へ進む。

## 元に戻す

WINのCustom JavaScriptを直貼り前の内容へ戻して保存する。テスト用の見出しとボタンはページに保存されない。今回のコードはページ本体の既存内容を削除しない。

このファイルは約200 KBのReact本体を含む。合格後はこの巨大なコードを残さず、GitHub Pagesなどの団体管理下のURLから`jsa-win.js`を読み込む運用へ切り替える。
